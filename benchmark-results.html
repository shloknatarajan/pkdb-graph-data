PK time-course extraction benchmark

How well can multimodal models recover structured pharmacokinetic curves from a scientific graph and its source paper?

TL;DR Across 12 complete runs, GPT-6 Astra set the accuracy ceiling at 0.893 micro F1 and 2.3% median relative error. GPT-6 Sol is the practical default: 0.817 F1, no failures, and an estimated $3.28 for the corpus. Claude Haiku 5.5 is the economy pick: 0.722 F1, no failures, and about $0.19, matching Luna’s rounded run cost while recovering 13 more curves. Haiku was also the fastest model at 25.9 seconds per figure. Claude Opus 5.5 reached 0.842 F1 but refused four figures.

How scoring works

A recovered curve must pass all three gates
Matching and alignment

Predicted curves are matched to gold curves using metadata agreement and scale-free shape distance. Points are aligned by time; interpolation is allowed within the observed range, but extrapolation is not.

Recovery criteria
  • Units convert into the gold unit
  • At least 50% of the gold time range is covered
  • Median relative error is no more than 20%

Micro F1 pools recovered, predicted, and gold curves across all figures. Macro F1 averages each figure’s F1, weighting a two-curve plot the same as a twenty-curve plot. Numeric quality is also reported directly through median relative error and point-level accuracy thresholds.

Caveats

  • One of the 39 benchmark figures has no scoreable values, leaving 38 figures and 204 curves in evaluation.
  • Intervention metadata is close to ungradeable because many gold labels are PK-DB-internal codes that cannot be derived from the graph or paper.
  • Dense per-subject figures remain difficult: models may count curves correctly while regularizing irregular marker positions into an invented sampling schedule.
  • Scores measure agreement with curator digitizations, which contain known curve-count and metadata inconsistencies.
  • Costs are estimates from recorded token usage and exclude free-tier credits, discounts, taxes, and retry overhead.
  • Claude Opus 5.5 refused four figures and Claude Fable 5.1 refused six. Those failures count against recovery, and their displayed costs estimate the missing refusal input usage.
  • Current Gemini runs use high media resolution and place the text prompt before the image. Older full runs are retained for context but do not all share the same prompt and request configuration.

Reproduce the benchmark

Use the oracle backend to verify the scorer without making an API call, or run a two-figure model smoke test before committing to the full corpus.

# scorer regression test
$ uv run --group evals python -m evals.run run --backend oracle

# current production candidate
$ export OPENAI_API_KEY=...
$ uv run --group evals python -m evals.run run --backend openai --model gpt-6-sol --limit 2 --workers 1

# latest Haiku, same benchmark configuration
$ uv run --group evals python -m evals.run predict --backend anthropic --model claude-haiku-5-5 --workers 2 --out predictions/full_claude-haiku-5-5.jsonl
$ uv run --group evals python -m evals.run score --predictions predictions/full_claude-haiku-5-5.jsonl --out reports/full_claude-haiku-5-5.json
